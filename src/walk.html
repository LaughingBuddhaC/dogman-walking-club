Record with the phone locked: start logging in GPSLogger, walk, stop logging. The recording shows up here – pick the walk it belongs to and the card follows. Standing still at the start or end is cut off.

Set up GPSLogger (Android, once)
  1. Install the free GPSLogger app: Google Play · F-Droid
  2. Settings → Logging details → Log to custom URL: switch it on and fill in (tap a value to copy it):
  3. Settings → Performance: log every 5 seconds and every 5 metres, so the route follows the paths.
  4. Android: location access Allow all the time, and Settings → Apps → GPSLogger → Battery → Unrestricted – otherwise the phone stops it when the screen is off.
  5. Each walk: tap Start logging (in the app, its widget or the notification), lock the phone, walk, then Stop logging.

Set up OwnTracks (once)
  1. Install the free OwnTracks app: iPhone · Android
  2. On this phone, tap the button and accept the import in OwnTracks:
    Connect OwnTracks ↗
  3. Location access: iPhone → Always. Android → Allow all the time and turn off battery optimisation for OwnTracks.
  4. At the start of each walk tap Set OwnTracks to Move; afterwards Quiet saves battery. Points sent outside a walk are thrown away.

Recorded with another app?

Tap Import GPX on a booking to add a route you recorded elsewhere. From Strava: open the activity on strava.com → ⋯ → Export GPX.
